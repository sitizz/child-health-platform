# Vision Analysis (Roadmap)

Planned camera-based ML capabilities:

1. **Wound / rash classification** — caregiver uploads a photo; model suggests likely category and non-diagnostic care guidance.
2. **Nutrition photo analysis** — food plate photos for caregiver-friendly nutrition tips.

Status: API contract only (`POST /api/v1/ml/vision/analyze` → HTTP 501).

The deterministic climate-health engine remains the decision-maker for environmental risk.
Vision models will never replace clinical diagnosis.
